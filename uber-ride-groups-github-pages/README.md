# Uber Ride Groups

An independent class-project concept for redesigning shared-ride checkout. The website explains the idea, includes an interactive simulated walkthrough, and links to the original Google AI Studio demo.

## Publish with GitHub Pages

In this repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then save. The root `index.html` is ready to publish; no build command is needed.

The ride and payment interactions on this site are simulated. The linked Google AI Studio demo may require Google sign-in.
