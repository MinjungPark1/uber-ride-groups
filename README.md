# Uber Groups

An independent class-project concept for sharing rides, ordering food together, and managing groups of friends. The website features three original video walkthroughs: Group Ride, Group Eats, and Account. It closes with a business-impact growth loop and feature-specific value drivers. The videos loop silently, with a pause button for each.

## Publish with GitHub Pages

Upload the contents of this project to the repository root, including `index.html`, `app.js`, `style.css`, and the entire `assets` folder. Do not upload the enclosing folder or the ZIP itself. In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then save. No build command is needed.

The booking, payment, and savings screens shown in the videos are illustrative class-project concepts.
